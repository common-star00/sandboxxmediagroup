# Skull & Scorpion Red Photography Update

This update restores the red/black Skull & Scorpion look while keeping SandboxX site navigation, contact slide effect, and the back-to-main link.

## Install

1. Replace your current `photography.html` with the included `photography.html`.
2. Open `skull-scorpion-red-css-addon.css`.
3. Copy all of it.
4. Paste it at the bottom of your current `style.css`.
5. Commit changes in GitHub.

## Important

Replace every instance of:

your-email@example.com

with the real email address where you want form messages sent.

## Red used

Skull & Scorpion Red: #c1121f

You can change it in the CSS here:

--skull-red: #c1121f;
